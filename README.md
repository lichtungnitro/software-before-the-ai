# Software Before the AI

**The last versions of popular apps before built-in LLM and generative-AI features arrived.**

This public, evidence-backed historical catalog tracks iOS, Android, and Windows versions separately. Traditional ML, recommenders, OCR, and classical NLP are allowed; integrated LLM assistants, Copilot-like features, generative writing, summarization, and image generation are disqualifying.

Research status is not a claim of verification. We never invent versions or download links, and we do not redistribute proprietary binaries. Old releases can contain serious security vulnerabilities.

See `docs/METHODOLOGY.md` for research standards and `data/apps.json` for targets. Run `python3 scripts/validate.py` to check dataset integrity.
